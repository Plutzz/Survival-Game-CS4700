# Lost

## Setup
https://plutz.itch.io/lost

## Features
#### Controls
  - Movement with WASD
  - I for inventory
    - Q and E to navigate pages within inventory
    - Click and drag for items
  - E for interaction
  - Esc for pause menu (includes join code)
#### Gameplay
Fight monsters, collect resourceds, and craft potions
